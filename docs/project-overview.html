04 Robust evaluation

AI Functions leave no traces — so we score the tables they leave behind.

Join each kept signal to its raw extracted entities and the chunk the extractor saw, then score it with three Databricks LLM judges via mlflow.genai.evaluate — reference-free.

entity_groundingEvery extracted place, org, policy & date is in the source — and pertinent, not incidental.
completeness · 0–1Of the fields the source actually supports, how many were captured.
go_relevanceIs the kept signal genuinely on GO's mission?
Next — a ground-truth setHand-labeling a gold sample unlocks fuller offline testing against a key.
Same judges, onlineThe identical scorers run as production monitoring on new signals.
Caveat. Judges aren't oracles — read the per-row rationales in the MLflow Evaluations tab, don't just trust the mean.
05 Reflection · data model & the graph

We kept a relational star — and left the graph in the backend.

The same facts fit two shapes. The star answers the dashboard's questions with plain joins; a raw node/edge graph looked compelling but we couldn't make it tell an end-user something they couldn't already read faster in the hotspot matrix.

Star is the system of recordSignal hub + dimensions + bridges — fast, joinable, easy to sync.
Graph reasoning stays server-sideShown as a hotspot matrix & explained mini-graphs, never a raw network.
A materialized graph waitsOnly a Could-have explorer (multi-hop, centrality) would justify it.
